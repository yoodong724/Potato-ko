# Potato Flowers in Full Bloom 한글 패치

비공식 한국어 패치입니다.

> [!WARNING]
> 아직 게임 전체 구간에 대한 플레이 검수가 끝나지 않았습니다. 진행 중 오역이나 표시 문제가 나타날 수 있습니다.

## 설치

1. [Releases](https://github.com/yoodong724/Potato-ko/releases/latest)에서 ZIP 파일을 받습니다.
2. 게임을 종료하고, ZIP 안의 `potato-ko` 폴더를 게임 폴더에 풉니다.
3. `potato-ko\install.cmd`를 실행합니다.
4. 게임의 언어 선택에서 `한국어`를 선택합니다.

제거하려면 게임을 종료하고 `potato-ko\uninstall.cmd`를 실행합니다.
